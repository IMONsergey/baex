# BAEX

Самостоятельная реализация сайта [REJOUICE](https://www.rejouice.com/) на React и TypeScript, подготовленная как основа для адаптации под BAEV. Исходный интерфейс разобран по реальным страницам, desktop/mobile состояниям и публичным стилям. Nuxt-сборка чужого сайта в приложение не включена.

Текущая версия сохраняет структуру референса, 19 проектов, галереи, локальные медиа и основные взаимодействия. Это reference edition: тексты сокращены и переписаны, названия и материалы проектов пока относятся к REJOUICE. Замена на BAEV вынесена в отдельный следующий этап. Этот README не означает, что сайт опубликован или подключен к рабочему домену.

## Запуск

Нужны Node.js 22.12+ и npm. Для проверки хешей медиа нужен Python 3.12+.

```bash
npm ci
npm run dev
```

Проверка и production-сборка:

```bash
npm run check
npm run build
npm run preview
```

`npm run check` проверяет TypeScript, целостность контента, внутренние переходы, наличие локальных файлов и хеши медиа. `npm run build` создает Vite-сборку в `dist/`, затем формирует отдельные `index.html` для всех 25 маршрутов.

Медиа находятся в репозитории, включая полный showreel. Один крупный ролик Terminal Industries хранится в `media-parts/` двумя частями. `npm ci`, `npm run dev`, `npm run check` и `npm run build` автоматически собирают его в `public/media/`, проверяя SHA-256 частей и готового MP4. Это локальная побайтовая сборка без сети и изменения качества. Отдельная команда: `npm run prepare:media`.

## Что реализовано

- Главная с крупным знаком, показом ролика, избранными проектами и интерактивными блоками агентства.
- Work с полноэкранной галереей, режимом List, наведениями, прокруткой и перетаскиванием списка. На телефоне используется последовательная галерея квадратных обложек.
- 19 страниц проектов с обложкой, ролями, описанием, медиа в исходных пропорциях, отзывами/наградами при наличии и переходом к следующему проекту.
- About, Services, Contact и служебная страница информации о референсе.
- Фиксированный header, мобильное меню с управлением клавиатурой, общий footer, переходы страниц и видеоплеер.
- Поддержка уменьшенного движения, отложенная загрузка видео и локальные постеры.

Прокрутка сохраняется отдельно для каждой записи истории. Back и Forward возвращают прежнее положение страницы после монтирования ее содержимого; якоря Services учитываются при отсутствии сохраненной позиции. Переходы также завершаются на экране ошибки загрузки, где Reload выполняет обычную перезагрузку страницы.

В Work List стрелки, Page Up / Down, Home / End и Space меняют выбранный проект вместе с реальным фокусом. Enter открывает выбранный кейс. При переключении Full / List и изменении ширины экрана фокус возвращается в доступную часть галереи.

Скрытые видеопревью не получают `src` до активации. Уход указателя останавливает превью и освобождает его ресурс; видео за пределами экрана или в скрытой вкладке ставится на паузу. Открытый showreel отдельно приостанавливает фоновые медиа.

Форма рассылки проверяет email только локально и честно сообщает, что подключение отсутствует. Она не отправляет данные в REJOUICE и не показывает фиктивную подписку. Контакты и ссылки референса остаются в конфигурации до замены на BAEV.

## Статический хостинг

Содержимое `dist/` нужно обслуживать от корня домена. Каждый известный маршрут получает настоящий входной файл, например `dist/work/rivian/index.html`, поэтому прямое открытие и обновление вложенного адреса доступны на сервере с поддержкой directory indexes. React загружает содержимое страницы на клиенте; это не серверный рендеринг.

Сборка не создает подменяющий страницу ошибки `404.html`. Для неизвестных адресов используется обычный ответ хостинга 404. В SPA-окружении также есть собственный экран неизвестного маршрута.

Размещение под префиксом вроде `/baex/` потребует согласованного изменения Vite `base`, basename роутера и путей локальных медиа. Обычная конфигурация рассчитана на `/`.

Reference edition содержит `noindex, nofollow`. Снимать это ограничение стоит при подготовке собственной версии BAEV с ее метаданными и контентом.

## Медиа и воспроизводимость

Источники, размеры и хеши записаны в `docs/asset-provenance.json`, графика в `docs/brand-provenance.json`. Подготовка и ограничения описаны в `docs/reference-assets.md`.

```bash
# Проверить уже сохраненные файлы без сетевых запросов
python3 scripts/sync-reference-assets.py --verify-only

# Восстановить отсутствующие файлы из зафиксированных источников
python3 scripts/sync-reference-assets.py
```

Для восстановления нужны Pillow, ffmpeg и ffprobe. Скрипт сверяет исходные и готовые хеши; изменившийся источник не принимается молча. Версии кодировщиков указаны в документации.

В исходном опубликованном Connect Homes обнаружены два недоступных editor-local blob-файла. Они описаны в `docs/source-gaps.json` и исключены из активной галереи. Остались все 19 проектов и 203 доступных галерейных элемента.

Медиа, знаки и шрифты референса принадлежат их правообладателям. Этот репозиторий не предоставляет на них новую лицензию. Для версии BAEV используются ее материалы и подходящие лицензии.

## Следующий этап: BAEV

Порядок адаптации и соответствие существующим блокам описаны в [docs/baev-adaptation.md](docs/baev-adaptation.md). Основные действия: заменить фирменные материалы и контакты, собрать собственные кейсы, переупаковать услуги, выбрать сцену для главной и подключить рабочую форму.
