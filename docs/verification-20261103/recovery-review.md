# Повторная проверка после восстановления BAEX

Дата: 2026-11-03.

Исходная восстановленная версия: `0e17f02fa0662fde786fe7f6d6396201bea63348`. Описанные ниже исправления и браузерные наблюдения относятся к рабочей копии после восстановления. Они не приписываются исходному коммиту.

Снимки первичной версии находятся в `../evidence/` и сохранены без изменений. Эта запись отделяет новые наблюдения от прежних кадров. Полный повтор каждого исходного снимка и автоматический pixel-diff не проводились.

## История и переходы

| Сценарий | Результат повторного браузерного прогона |
|---|---|
| About → Services | До перехода About находился на `scrollY=4925`; Services прокручен до `scrollY=936`. |

| Forward | Services восстановлен ровно на `936`. |
| Services → Venture | Итоговый `scrollY=5190`; верх элемента Venture находится на `90px` ниже верхнего края viewport. |

Позиции сохраняются по ключу конкретной history entry. Восстановление выполняется после монтирования lazy route, с обновлением ScrollTrigger и повторным применением позиции через requestAnimationFrame.

В focused code review дополнительно исправлены три случая:

- Error fallback участвует в готовности маршрута и освобождает шторку; Reload выполняет полную перезагрузку текущего URL.
- Cleanup предыдущего маршрута блокирует запись промежуточной прокрутки, чтобы короткий Suspense fallback не затирал сохраненную позицию.
- Смена `location.key` инвалидирует отложенный переход, чтобы старый callback анимации не перебивал быстрый Back.

Эти три случая подтверждены чтением исправленного кода. Отдельный браузерный прогон с принудительной ошибкой chunk или детерминированной задержкой lazy import в этой записи не заявляется.

## Согласование с завершившимся предыдущим запуском

Во время восстановления в удаленном `main` появился коммит `995a93e57c6bc737783f3ec05ad1ac7e9eea9277`. Его дерево сравнено с восстановленным исходным коммитом. Дополнительные изменения касались только передачи двух крупных MP4: пяти частей, скрипта их сборки, npm hooks и документации. Изменений исходного интерфейса или контента в этом коммите не было.

Текущая версия хранит полный showreel целым MP4. Для одного ролика Terminal Industries сохранены две части и локальная автоматическая сборка с проверкой SHA-256; готовый файл имеет прежние Git SHA и SHA-256. Передача единого Terminal blob через Mac не была подтверждена после потери ответа устройства, поэтому в дерево включен уже проверенный вариант из двух частей. Новый коммит продолжает удаленную историю, включая завершившийся предыдущий запуск.

Проверка чистого восстановления: готовый Terminal MP4 сохранен вне проекта, затем выполнен `npm ci --prefer-offline --no-audit --no-fund`. Postinstall сообщил `1 assembled locally`. Восстановленный файл имеет SHA-256 `f97c3cd2c2ba6b1aea595e372f875ec0732cee09d71c64cb1be5e59ca7c25eff` и Git blob SHA `91615d1bba0dcda6840fe357900265da3115a30f`. Повторные check/build прошли.

Это ручные focused browser checks и отдельная сверка данных. Все 19 галерей целиком повторно не прокручивались; реальные Safari/iOS/Android устройства и полный набор pointer-состояний не проверялись.
