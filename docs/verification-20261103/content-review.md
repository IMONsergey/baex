## Объясненные различия

- Две записи Connect Homes по-прежнему содержат временные editor-local `blob:` URL. Это недоступные ресурсы источника, уже описанные в `../source-gaps.json`. В React включены остальные пять элементов этого кейса в исходном порядке.
- Поле `project_reel` встречается в данных четырнадцати проектов, но текущий renderer исходного сайта его не использует. Его отсутствие в активной React-галерее не является потерей видимого контента.
- У седьмого glance widget есть запасной `background_image` и `background_media`. Исходный renderer предпочитает видео, React использует то же видео. Запасная картинка не нужна для этого состояния.
- Число наград нормализовано из строки `"90"` в число `90`.
- Некорректные повторные query-параметры отдельных исходных CDN URL сохранены как provenance. Runtime разрешает медиа локально и не отправляет запросы по этим строкам.

В JSON есть 15 вхождений исходных медиа, не включенных в активный набор: четырнадцать неиспользуемых `project_reel` и одна запасная картинка glance widget. Это не пятнадцать отсутствующих видимых элементов.

В репозиторий сохранен отчет сравнения. Скомпилированный Nuxt runtime исходного сайта не включен в приложение.
